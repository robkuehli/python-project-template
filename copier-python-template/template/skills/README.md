# Skills

Reusable, on-demand capabilities for coding agents, in the open
[Agent Skills](https://agents.md) `SKILL.md` format. Each skill is a folder with
a `SKILL.md` file (name + description frontmatter, then Markdown instructions)
that an agent loads only when relevant.

Add one skill per folder, e.g. `skills/release-checklist/SKILL.md`.
